# Roadmap

## v0.1 — sekarang
- [x] Kota prosedural 10×10 blok, 6 distrik + landmark
- [x] Jalan kaki & mobil, bajak kendaraan
- [x] Lalu lintas AI + pejalan kaki
- [x] Bintang pencarian + pengejaran polisi + tumbang/tertangkap
- [x] Misi kurir berulang + 10 koin koleksi
- [x] Siklus siang-malam, bloom, soft shadow
- [x] Audio prosedural + radio generatif
- [x] Simpan otomatis (localStorage)

## v0.2 — gameplay
- [ ] Sepeda motor (model + fisika miring)
- [ ] Senjata sederhana (pistol) dengan penargetan otomatis
- [ ] Bengkel: perbaiki & ganti warna mobil dengan uang
- [ ] Misi kedua: "angkot rute" — antar penumpang ke halte berurutan
- [ ] Polisi jalan kaki mengejar & menembak (bukan cuma ngebut)
- [ ] Statistik akhir hari (jarak tempuh, uang, kekacauan)

## v0.3 — dunia
- [ ] Interior sederhana (warung, klinik) dengan pintu masuk
- [ ] Jembatan penyeberangan & flyover di pusat kota
- [ ] Hujan + jalan basah (refleksi sederhana)
- [ ] Kereta api yang berputar di jalur luar kota
- [ ] Kapal kecil di dermaga yang bisa dinaiki

## v0.4 — teknis
- [ ] LOD / frustum per-distrik supaya kota bisa 3× lebih luas
- [ ] Simpan posisi pemain & kondisi dunia (bukan cuma progres)
- [ ] Gamepad support
- [ ] Kontrol sentuh untuk HP (joystick virtual)
- [ ] Web Worker untuk pembangkitan kota (hilangkan hitch loading)

## Ide yang dulu
- Multiplayer co-op sederhana (WebRTC)
- Editor misi untuk pemain
- Mode foto dengan depth-of-field
